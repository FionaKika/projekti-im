
# Appointment Organizer

## Project Overview
Appointment Organizer is a mobile application designed to simplify appointment booking and management for beauty salons.

## Target Users
- Customers who want to book beauty salon appointments.
- Salon owners and administrators who manage services and bookings.

## Main Features
- Browse available salon services.
- View service prices and durations.
- Book appointments.
- View and manage appointments.
- Cancel or reschedule bookings.
- Manage salon services and availability.

## Technology
- React Native
- Expo
- TypeScript
- Supabase
- PostgreSQL

## Development Guidelines
- Use TypeScript.
- Keep components reusable.
- Keep database logic separate from UI components.
- Use environment variables for Supabase configuration.
- Test features on a physical phone using Expo Go.
- Commit after each working development step.
